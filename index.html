TELA 4 DE 8 · BLOCO 2A 35–55 min Micro-Roteiro · Página 2

Cadastre um novo ecoponto no array

Arquivo js/app.js · lista LOCAIS_COLETA · no final da lista, antes do ];

js/app.js 
  },   // <- coloque a vírgula aqui
  {
    nome: "Meu Ecoponto",
    bairro: "Meu Bairro",
    categoria: "Oleo",
    horario: "Sabados, 09h as 13h",
    mapaUrl: "https://maps.google.com/?q=Garopaba"
  }
];
⚠️ Erro nº 1 dos iniciantesEsqueceu a vírgula depois do } anterior? A lista inteira para de funcionar.
🏷️ A categoria precisa ser igual a um botão
ReciclaveisVidroEletronicosOleo

TELA 5 DE 8 · BLOCO 2B 55–70 min Micro-Roteiro · Página 2

Teste os filtros e o link do Google Maps

index.html · cada botão 
<button class="btn-filtro" onclick="filtrarEcopontos('Vidro')">Vidro</button>
js/app.js · o filtro 
const filtrados = categoriaEscolhida === "Todos"
  ? LOCAIS_COLETA
  : LOCAIS_COLETA.filter(item => item.categoria === categoriaEscolhida);

💡 .filter() guarda só os locais cuja categoria é igual ao botão clicado.

🧪 Experimente aqui (simulação)
  1. Clique em cada botão
  2. Veja só aquele tipo
  3. Abra o link do Google Maps
🏁 Checkpoint de vitóriaTodos os filtros respondem e o mapa abre no local certo.
TELA 6 DE 8 · BLOCO 3 70–95 min Micro-Roteiro · Página 3

Suba no GitHub e ative o Pages

  1. github.com → New repository → nome painel-verde · Public
  2. uploading an existing file → arraste index.html, css/ e js/ → Commit changes
  3. Settings → Pages → Branch main / /(root) → Save
  4. Aguarde ~1 min e abra https://SEU-USUARIO.github.io/painel-verde/
⚠️ Se aparecer erro 404index.html precisa estar na raiz do repositório, não dentro de uma pasta.
🏁 Checkpoint de vitóriaSeu painel abre no endereço .github.io, não pelo arquivo do computador.
TELA 7 DE 8 · BLOCO 4 95–110 min Micro-Roteiro · Página 4

Gere o QR Code do seu Painel e poste no Mural

  1. Cole a URL .github.io do seu painel no gerador ao lado
  2. Clique em Baixar PNG
  3. No Moodle, abra o Mural do Curso 2 e poste QR + link
  4. Teste no celular de um colega 📱
⬇ Baixar PNG

Funciona offline depois de carregado. Nada é enviado a servidores.

🏁 Checkpoint de vitóriaO Painel Verde abre no celular de outra pessoa pelo QR Code.
