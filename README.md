# Slides-Guia de Projeção — Painel Verde de Garopaba (Curso 2)

Frente 3 · SNCT 2026 · Programação para a Internet 2 · IFSC Câmpus Garopaba

8 telas para projetar na oficina (legíveis a 6 m), em HTML + Bootstrap 5 + JS puro.

## Como usar
- **Projetar:** abra `index.html` (ou o link do GitHub Pages) em tela cheia (F11).
- **Teclado:** `→` / `Espaço` avança (passo a passo) · `←` volta · `1`–`8` vai à tela · `G` visão geral · `P` pausa o cronômetro.
- **Modo aluno** (todo o conteúdo visível, sem passo a passo): `index.html?modo=aluno`
- **Link da pesquisa de satisfação (tela 8):** `index.html?pesquisa=https://...` ou edite `CONFIG.pesquisa` em `script.js`.
- **Plano B offline:** `Slides-Guia-Painel-Verde.pdf` (8 páginas A4 paisagem) no pen-drive.

## Arquivos
| Arquivo | Função |
|---|---|
| `index.html` | 8 telas |
| `style.css` | tema, projeção e impressão |
| `script.js` | navegação, cronômetro, QR, simulador |
| `Slides-Guia-Painel-Verde.pdf` | cópia offline |
